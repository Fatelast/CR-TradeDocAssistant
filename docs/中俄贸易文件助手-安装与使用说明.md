# 中俄贸易文件助手｜安装与使用说明

> 适用版本：`0.6.0-beta.1` 内部测试版  
> 支持系统：Windows 10/11 x64  
> 运行方式：完全离线，不需要安装 Node.js 或 Python

## 1. 安装

1. 获取 `CR-TradeDocAssistant-0.6.0-beta.1-x64-setup.exe` 和 `SHA256SUMS.txt`；
2. 对照 SHA-256 校验安装包完整性；
3. 双击安装包，选择当前用户安装和安装目录；
4. 内测包暂未进行代码签名，Windows 可能显示“未知发布者”；只有在文件来源和校验值都可信时才继续；
5. 安装完成后从开始菜单或桌面快捷方式启动。

默认当前用户安装不要求管理员权限；若手动选择受保护的系统目录，Windows 可能要求额外权限。安装程序不会安装服务器、数据库服务或系统 Python。

## 2. 基本工作流

```text
选择 Excel
→ 选择工作表和列
→ 创建离线任务
→ 小批次匹配
→ 人工审核与编辑
→ 导出预检
→ 生成新的 Excel 副本
```

应用不会覆盖源文件，也不会覆盖已经存在的输出文件。术语和缓存命中只生成候选，仍需人工确认。

## 3. 四个模块

- **工作台**：导入、解析、离线匹配、审核和安全导出；
- **任务历史**：查看任务详情、导出记录、可信打开和重新执行；
- **术语与缓存**：维护术语 XLSX、查询和清理精确缓存；
- **设置与维护**：设置默认输出目录、批次大小、日志级别和本地数据清理。

## 4. 本地数据

默认数据位置：

```text
%APPDATA%\中俄贸易文件助手\data\app.db
%APPDATA%\中俄贸易文件助手\logs\main-YYYY-MM-DD.log
```

业务 Excel 保存在用户自己选择的目录，不会复制进应用数据库。日志只记录运行信息、错误和脱敏路径，不保存完整业务文本。

需要手工备份时：

1. 先完全退出应用；
2. 复制整个 `%APPDATA%\中俄贸易文件助手\data` 目录；
3. 同时保留源 Excel 和导出 Excel；
4. 当前版本没有 SQLite 整库恢复界面，不要在应用运行时替换数据库文件。

## 5. 升级与卸载

- 覆盖升级前建议备份 `data` 目录；
- 升级会保留历史、术语、缓存和设置；
- 卸载器默认保留 `%APPDATA%\中俄贸易文件助手`；
- 卸载不会删除源 Excel 或输出 Excel；
- 如需彻底清理本地记录，应先在应用内查看清理预览并确认范围。

## 6. 常见问题

### 应用显示 Worker 异常

完全退出后重新启动。若仍异常，在设置页将日志级别设为 `info`，复现一次并提供当日日志。不要发送业务 Excel 或未脱敏截图。

### Excel 无法导出

检查源文件是否变化、是否被 Excel/WPS 占用、输出文件是否已存在，以及工作簿是否包含高风险对象。应用不会自动覆盖已有文件。

### Windows 阻止安装

内测包暂未签名。先核对来源和 SHA-256，再通过 Windows 的“更多信息”查看发布者提示。正式对外发布前应采购代码签名证书。

### 是否需要联网

不需要。当前版本没有在线翻译、账号登录、云同步或业务数据上传。
