# 中俄贸易文件助手 `0.6.0-beta.1` 发布说明

> 发布定位：M5 工程内测版，不是 `1.0.0` 正式版。  
> 构建日期：2026-07-31  
> 支持平台：Windows 10/11 x64，当前用户 NSIS 安装。

## 发布产物

- 安装包：`CR-TradeDocAssistant-0.6.0-beta.1-x64-setup.exe`
- 安装包大小：126,401,379 字节（120.55 MiB）
- SHA-256：`b5562fc4922f213c948c45d0cfe1202d652c19ab009c8c2c8a60e9a2e67a403c`
- 校验文件：`release/SHA256SUMS.txt`
- 默认安装目录：`%LOCALAPPDATA%\Programs\CR-TradeDocAssistant`

## 本版本完成内容

- 将 Python Excel Worker 冻结为独立 `onedir` 可执行程序并随安装包分发；
- 桌面端按开发/生产环境选择 Python 源码入口或随包 Worker EXE；
- 通过 UTF-8 JSON Lines 保持中文字段、协议 `1.0` 和 schema `3`；
- 使用 Electron ASAR、`extraResources` 和 NSIS x64 生成当前用户安装包；
- 安装器支持选择安装目录，卸载默认保留 AppData；
- 提供应用图标、第三方许可、安装说明、发布清单和 SHA-256 校验；
- `npm run verify:release` 可完成测试、冻结、冒烟、打包和产物校验。

- 桌面/开始菜单快捷方式、Windows GUI 子系统和退出后的无残留 Worker 验证通过；

## 已知限制与发布边界

- 当前版本未启用在线翻译、自动更新、代码签名和时间戳服务；代码签名已明确不纳入当前 V1 交付；
- Windows 可能显示“未知发布者”或 SmartScreen 提示；
- 安装包只生成 x64 架构，不支持 32 位 Windows 和 ARM64；
- 尚未在无 Node.js、无 Python、断网的 Windows 10/11 干净虚拟机完成双版本验收；
- 尚未使用脱敏真实贸易 Excel 完成 16 类文件矩阵、Microsoft Excel/WPS 重开和样式验收；
- schema v2/v3 真实数据副本覆盖升级、同版本重复安装和 beta 升级仍需独立验收；
- 尚未完成贸易操作人员抽查和业务验收签字；
- 在上述外部发布门槛完成前，不得将版本提升为 `1.0.0`。
