## C. Beta 轻量验收（`0.6.0-beta.1`）

### C.1 脱敏演示样本技术闭环

样本位于 `resources/samples/`，均为合成数据，不含客户、供应商、金额、联系方式或报关信息：

- `m5-beta-basic.xlsx`：基础单工作表、已有译文列；
- `m5-beta-existing-target.xlsx`：非首行表头、已有部分译文和多语言数字混排；
- `m5-beta-multisheet.xlsx`：多工作表、合并标题、冻结窗格、样式和公式。

执行：

```powershell
npm run verify:beta-samples
```

该命令会校验三份输入的 SHA-256、工作簿结构和行映射，并以 Worker 协议完成“导入 → 人工填充模拟 → 导出 → 输出重读”。它同时断言源文件哈希未改变，并在清单要求时比对导出前后的样式和公式。该检查不替代 C.2 的办公软件人工复开。

- [x] 三份样本技术闭环通过；
- [x] 三份输入样本 SHA-256 均未改变；
- [x] 三份导出文件可由 Worker 再次解析。

### C.2 一次人工办公软件复开

在已安装 **Microsoft Excel 或 WPS 二选一** 的 Windows 电脑上，任选 C.1 的一个导出文件完成以下操作，通常不超过 10 分钟：

1. 记录输入文件 SHA-256，启动已安装的 Beta 应用；
2. 导入样本，按清单选择工作表、表头行、原文列和译文列；
3. 对未完成行填写中文译文，完成审核并导出到新文件；
4. 用 Excel 或 WPS 打开导出文件，确认可正常显示、原文未被覆盖、译文写入预期列；
5. 再次计算输入 SHA-256，必须与第 1 步一致；在本文件记录软件名称、版本、样本名、日期和结论。

| 记录项 | 当前值 |
| --- | --- |
| 状态 | 待执行：当前开发机未发现 Microsoft Excel 或 WPS 可执行程序 |
| 建议样本 | `m5-beta-multisheet.xlsx` |
| 执行软件 | 待填写 |
| 软件版本 | 待填写 |
| 执行日期与结论 | 待填写 |
