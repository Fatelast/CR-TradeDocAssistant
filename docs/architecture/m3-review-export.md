# 中俄贸易文件助手｜M3 审核与安全导出知识快照

## 阶段结论

M3 已完成从可恢复离线翻译任务到可验证 Excel 副本的闭环：

```text
加载已完成或待审核任务
→ 搜索、筛选和逐行复核
→ 确认、忽略、恢复初始候选或离线重新匹配
→ 校验任务完成度与源文件指纹
→ 重新解析 Excel 风险并确定目标列
→ 原生另存为选择输出位置
→ 同目录临时文件写入
→ 重新打开并逐格验证
→ 原子移动为最终 .xlsx 副本
```

当前仍不启用在线翻译或本地大模型。M3 只把 `completed` 行写入 Excel；`ignored` 行保持原值，其他状态全部阻止导出。

## 核心实现

- SQLite schema 升级至 `2`，任务保存源文件 SHA-256、字节数、修改时间、受限状态和风险快照；
- 任务行保存初始候选和初始候选来源，以支持恢复初始候选和识别人工修改；
- 审核动作包括忽略、恢复初始候选和离线重新匹配；重新匹配仍只使用精确缓存与本地术语；
- 导出前重新计算源文件指纹，并重新执行工作簿风险解析；
- Renderer 只提交 `taskId`，输出路径只能由 Electron Main 的原生另存为对话框产生；
- Worker 拒绝原文件路径、已存在的输出路径、非 `.xlsx` 路径和受限工作簿；
- 写入以稳定 Excel 坐标为准，不依赖界面数组顺序；
- 保存到目标目录内的临时文件，重新打开并验证全部计划写入单元格后，才移动为最终文件。

## 数据模型与协议

SQLite schema `2` 在 M2 基础上新增：

| 字段 | 用途 |
|---|---|
| `source_file_sha256` | 任务创建时的源文件内容指纹 |
| `source_file_size_bytes` | 快速辅助识别源文件变化 |
| `source_file_mtime_ns` | 保存诊断信息，不单独作为身份依据 |
| `source_restricted` | 保存创建任务时的导出限制 |
| `source_risks_json` | 保存创建任务时的风险快照 |
| `initial_translation` | 保存该行最初候选或已有译文 |
| `initial_candidate_source` | 保存初始候选来源 |

协议版本仍为 `1.0`，应用与 Worker 版本为 `0.4.0`。新增 Worker 动作：

- `review_translation_row`
- `preflight_export`
- `export_translation_task`

新增 Renderer IPC：

- `translation:review-row`
- `export:preflight`
- `export:select-and-run`

## 导出判定

| 条件 | 结果 |
|---|---|
| 所有行均为 `completed` 或 `ignored` | 允许继续预检 |
| 存在 `pending`、`candidate`、`needs_manual` 或 `failed` | 阻止导出 |
| 源文件缺少历史指纹 | 阻止导出，需重新创建任务 |
| 源文件内容或大小变化 | 阻止导出，需重新导入 |
| 工作簿被标记为受限 | 阻止导出，不提供强制绕过 |
| 目标列已存在 | 只写入已确认译文；相同值保持不动 |
| 目标列不存在 | 追加到有效数据区最右侧，并复制源列基础样式 |
| 目标路径等于原文件或已经存在 | 阻止导出 |
| 目标单元格位于不可写合并区域 | 阻止导出 |
| 重开验证失败 | 删除临时文件，不生成最终输出 |

## 格式保留边界

- 使用 `data_only=False`，保留公式表达式；
- 不插入中间列，不改变行顺序；
- 不修改非目标工作表和非目标列；
- 新列复制源列宽度、表头样式和逐行基础样式；
- 已有目标值和 `ignored` 行默认保持不动；
- 条件格式、数据验证、图表、绘图对象和外部链接等高风险工作簿仍禁止导出；
- “格式保留”指固定回归样本验证的主要结构、公式和样式，不宣称任意复杂 Excel 完全无损。

## M4 继续开发时的约束

- 历史记录、输出文件索引、术语导入导出和设置页属于 M4，不应反向改变 M3 的写回安全边界；
- 任务、缓存和日志需要独立的 90/180/30 天清理策略及二次确认；
- 导出历史若保存路径或哈希，只保存本机元数据，不复制业务文件；
- 任何在线翻译能力仍需单独确认费用、数据外发、凭据存储和隐私边界；
- M5 打包前仍需用 Microsoft Excel 对脱敏真实样本做人工兼容性回归。
