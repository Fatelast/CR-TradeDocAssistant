# 中俄贸易文件助手｜M4 本地数据与可维护性设计

> 目标版本：`0.5.0`
> 数据库版本：`3`
> Worker 协议版本：`1.0`
> 设计状态：已实施（2026-07-31）

## 1. 阶段目标

M4 将 M3 已完成的“导入 → 离线翻译 → 审核 → 安全导出”闭环扩展为可长期维护的本地数据工作台：

- 持久化任务及每次导出记录；
- 提供任务历史、筛选、详情、重新执行和安全删除；
- 提供术语库管理及标准 `.xlsx` 导入导出；
- 提供精确缓存查询和清理；
- 提供少量真正生效的本地设置；
- 落实任务 90 天、缓存 180 天、日志 30 天的固定保留策略；
- 保持完全离线和 M3 文件安全边界。

M4 不接入在线翻译、本地模型、API 配置、遥测、SQLite 整库备份或数据库恢复。

## 2. 已确认决策

1. SQLite 整库备份与恢复延后；M4 只提供术语导入导出和设置导出。
2. 应用启动时每天最多执行一次自动清理：
   - 完成或中止任务保留 90 天；
   - 精确缓存保留 180 天；
   - 本地日志保留 30 天。
3. 历史删除采用数据库硬删除，并级联任务行与导出记录；不删除任何 Excel 文件。
4. 历史任务重新执行始终创建新任务并重新读取源文件；旧任务保持不可变。
5. 术语导入导出只支持标准 `.xlsx` 模板。
6. 精确缓存只允许查看和清理，不允许直接编辑译文。
7. 不引入 Vue Router、Pinia、网络服务或后台数据库进程。

## 3. 架构边界

```text
Vue 应用外壳
├─ 工作台（M1—M3）
├─ 任务历史
├─ 术语与缓存
└─ 设置与数据维护
        ↓
Preload 白名单
        ↓
Electron Main
├─ IPC 字段校验
├─ 原生文件/目录选择器
├─ 临时会话与一次性确认
├─ 可信路径打开
└─ 日志轮转与日志清理
        ↓
Python Worker
├─ 任务/导出历史
├─ 术语 XLSX 导入导出
├─ 精确缓存
├─ 设置
├─ 数据清理
└─ SQLite schema v3
```

Renderer 不能提交待打开、导入、导出或删除的任意本地路径。Python Worker 仍是 SQLite 的唯一读写者。

## 4. SQLite schema v3

### 4.1 `task_exports`

每次导出独立记录：

- `id`
- `task_id`
- `output_file_path`
- `output_file_name`
- `output_file_sha256`
- `status`：`pending`、`completed`、`recovered`、`failed`
- `sheet_name`
- `target_column`
- `target_column_letter`
- `created_target_column`
- `written_rows`
- `skipped_rows`
- `validated`
- `error_code`
- `created_at`
- `completed_at`

导出开始前创建 `pending` 记录；文件重开验证成功后更新为 `completed`。应用启动时检查遗留 `pending` 记录：可信输出存在且可读取时标记 `recovered`，否则标记 `failed`。

M3 以前的导出结果没有持久化路径，M4 不扫描磁盘猜测或回填历史。

### 4.2 `app_settings`

采用单行强类型设置：

- `default_output_directory`
- `batch_size`：默认 50，范围 1～200
- `log_level`：`info` 或 `error`
- `updated_at`

固定保留期限只展示，不允许在 M4 修改。

### 4.3 现有表调整

- `tasks` 增加 `rerun_of_task_id`；
- `glossary_terms` 增加规范化 `term_key` 和唯一索引；
- `app_meta` 保存最后自动清理时间和清理摘要；
- 为历史、导出时间、术语分类和缓存过期时间增加必要索引。

schema v2 → v3 必须保留已有任务、任务行、术语和缓存。

## 5. 任务历史

历史列表支持：

- 文件名搜索；
- 7/30/90 天和全部时间；
- 任务状态筛选；
- 分页；
- 最近导出状态；
- 源文件与输出文件存在性。

历史详情展示任务配置、行状态统计、源文件指纹与风险、重执行关系和全部导出记录。打开文件时 Renderer 只提交 `taskId` 或 `exportId`，Main 从 Worker 查询可信路径后调用系统能力。

重新执行流程：

1. 读取旧任务配置；
2. 重新校验源文件；
3. 文件未变化时创建新任务；
4. 文件缺失或变化时返回“需要重新选择源文件”；
5. 新任务保存 `rerun_of_task_id`；
6. 旧任务和旧导出记录保持不变。

历史删除规则：

- 仅终态任务可删除；
- 运行中或暂停任务必须先中止；
- 删除前返回任务、任务行和导出记录数量；
- 用户在应用内二次确认后执行；
- 数据库记录永久删除，业务文件不在删除范围。

## 6. 术语与缓存

### 6.1 术语管理

支持搜索、分类、启用状态筛选、新增、编辑、启用和停用。不提供术语删除。

`term_key` 由规范化俄文、精确匹配和大小写选项生成。任何有效术语变更只递增一次术语库版本。

### 6.2 XLSX 导入

标准模板列：

| 俄文原文 | 中文译文 | 分类 | 精确匹配 | 区分大小写 | 启用 | 备注 |
|---|---|---|---|---|---|---|

边界：

- 最大 5 MiB；
- 最多 5,000 条；
- 固定模板表头；
- 预检展示新增、更新、未变化和错误数量；
- 无效行或文件内重复术语会阻止导入；
- 与已有术语冲突时计为更新；
- 确认后在单个事务中完成；
- 文件在预检后变化时拒绝应用；
- 一次批量导入只递增一次术语版本。

Main 保存一次性导入会话和可信路径，Renderer 只持有文件 SHA-256 作为一次性确认令牌，不接触真实路径。

### 6.3 XLSX 导出

导出全部术语，包括停用项。Main 使用原生另存为对话框取得目标路径，Worker 通过临时文件保存并重开验证，不覆盖已有文件。

### 6.4 精确缓存

支持搜索原文和译文，查看确认时间、最后使用时间和过期时间，并支持：

- 删除选中缓存；
- 清理已过期缓存；
- 清空全部缓存。

所有清理操作都需要范围预览和应用内二次确认。

## 7. 设置与数据维护

可修改设置：

- 默认输出目录：只能通过 Main 原生目录选择器设置；
- 批次大小：1～200；
- 日志级别：`info` 或 `error`；
- 设置导出：本地 JSON，只用于查看和迁移参考，不支持自动恢复。

默认输出目录不存在时，翻译副本对话框回退到源文件目录，术语和设置导出回退到系统文档目录。

自动清理：

- 应用启动后触发；
- 每 24 小时最多一次；
- 只自动删除 90 天前的完成/中止任务；
- 未完成任务永不自动删除；
- 依据 `expires_at` 删除过期缓存；
- Main 只删除符合应用日志命名规则且超过 30 天的日志；
- 失败不阻止应用启动。

手动清理可独立选择过期任务、过期缓存、全部缓存和过期日志。执行前展示数据库记录数量、日志文件数量与日志字节数，并用包含记录修订信息的 `planHash` 绑定预览范围。

日志改为按日期轮转：`main-YYYY-MM-DD.log`。

## 8. 桌面界面

应用外壳增加四个模块：

1. 工作台；
2. 任务历史；
3. 术语与缓存；
4. 设置与数据维护。

继续使用现有深绿色工业台账视觉语言。工作流阶段栏只在工作台中展示，模块导航独立存在。

Renderer 组件：

- `App.vue`：保留既有 M1—M3 工作台状态与流程，避免为 M4 做高风险搬迁；
- `HistoryPanel.vue`：历史列表、详情、重新执行与删除确认；
- `DataLibraryPanel.vue`：术语、XLSX 导入导出与精确缓存；
- `SettingsPanel.vue`：强类型设置、固定保留策略与清理确认。

视图切换保持工作台状态，不引入路由或全局状态库。确认区域直接放在对应模块的操作上下文中，不使用浏览器原生确认框。

## 10. 验收标准

- schema v2 数据可无损迁移至 v3；
- 新导出在重启后仍可查询；
- 重新执行不会修改旧任务；
- 文件路径失效只提示，不删除历史；
- 术语导入为全有或全无；
- 术语导出可重新打开；
- 缓存不可直接编辑；
- 自动清理只处理固定范围；
- 手动删除和清理具备预览与二次确认；
- 所有清理都不会删除 Excel；
- 设置、历史、术语和缓存重启后仍存在；
- 应用保持完全离线。
